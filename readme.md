# Análise de Satisfação de Clientes — NPS

Projeto desenvolvido como parte do Tech Challenge da
pós-graduação em Ciência de Dados da FIAP.

## Objetivo

Investigar os fatores associados à satisfação dos clientes,
com foco em identificar:

- Quais fatores parecem mais críticos para a satisfação.
- Quais características estão associadas aos detratores.
- Se existe um ponto de ruptura na experiência do cliente.

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Scikit-learn

## Arquivos do projeto

- `tech_challenge_01.ipynb`: notebook com as análises.
- `requirements.txt`: bibliotecas e versões utilizadas.
- `.gitignore`: arquivos e pastas ignorados pelo Git.

## Como executar

Os comandos abaixo são para Windows e PowerShell.

1. Crie um ambiente virtual:
   `py -3.12 -m venv .venv`

2. Ative o ambiente:
   `.\.venv\Scripts\Activate.ps1`

3. Instale as dependências:
   `python -m pip install -r requirements.txt`

4. Abra o notebook no VS Code e selecione o kernel da `.venv`.
